# NULL VOID (working title): menus prototype

The front end of the game: main menu, lobby, loadouts and the weapon workshop.
No matches are playable yet. That comes next.

## How to build (Windows, Visual Studio)

1. Put this folder somewhere new, e.g. `Documents\NullVoid` (keep `CMakeLists.txt` next to the `src` and `assets` folders).
2. Visual Studio > **Open a local folder** > pick that folder.
3. Wait for CMake to finish (the first time it downloads raylib, which takes a minute).
4. Pick **game.exe** in the green Play dropdown and press Play.

## Screens

| Screen | What it does |
| --- | --- |
| Main menu | MULTIPLAYER or ZOMBIES (both open the lobby), SETTINGS (placeholder), QUIT |
| Lobby | Your soldier in the middle (drag to spin), QUICK PLAY and FILTERS on the left, featured modes such as CRATE RUSH 24/7, daily challenges on the right |
| Loadouts | Pick a loadout, swap weapons with `<` `>`, click equipment to cycle it, click a weapon to customize it |
| Workshop: Attachments | Click a slot label around the weapon (muzzle, barrel, laser, optic, underbarrel, magazine, stock). Hover an attachment to preview it and its stat changes. Max 5 attachments |
| Workshop: Appearance | Camos grouped into Military, Special and Mastery, each with its unlock challenge |
| Workshop: Progression | Weapon level, XP and every unlock in order. The TESTING buttons give XP so you can try unlocking things |

**ESC** always goes back one screen.

## Files

| File | What's in it |
| --- | --- |
| `main.cpp` | Opens the window and switches between screens |
| `App.h` | The `App` struct: which screen you're on, your profile and what's selected |
| `GameData.h/.cpp` | Weapons, attachments, camos, equipment, XP and stat math |
| `Assets.h/.cpp` | Box-built 3D weapon and soldier, and the camo textures (generated by code, no image files) |
| `Ui.h/.cpp` | Colors and reusable buttons, tabs, panels and stat bars |
| `Common.cpp` | Top bar and drag-to-rotate shared by several screens |
| `MainMenu.cpp`, `Lobby.cpp`, `Loadouts.cpp`, `Workshop.cpp` | One file per screen |
| `assets/fonts/` | The menu font, Barlow Semi Condensed (free under the SIL Open Font License, see `OFL.txt`). The build copies `assets` next to `game.exe` |

## Names

Every name here (game title, weapons, attachments, camos, modes) is original and a placeholder.
To rename the game, change `GAME_TITLE` in `GameData.h`.
